# Loaner laptop return procedure and handling notes

## Before the appointment

Use the asset register to find the loaner record. Check the recorded asset tag and the due date. Ask the borrower to bring the laptop and charger. Prepare a reusable equipment bag for an ordinary return. The return status records where the laptop is in the process. The service desk checks the daily return list at close.

## Intake checklist

Scan the tag and compare it with the loaner record. If the tag differs, stop. Set status Check required and refer the tag discrepancy to the Asset Desk. Keep the laptop in intake and wait for resolution. Do not close the record. For a matching tag, check the charger and inspect the laptop for damage before powering it on.

## Damage classes

Surface scratches alone do not change the normal process. Photograph the scratches and continue. Visible battery swelling requires special handling even if the tag matches. Do not power on or charge the laptop. Move it to the designated battery isolation cabinet, set status Safety hold, and call Facilities on extension 418. Record the tag, location, and time in the incident log, and leave the loan open until Facilities clears it.

## Closing an ordinary return

With a matching tag and no battery swelling, give the borrower an acknowledgment. If the charger is missing, set status Accessories pending, note the missing charger in the asset register, and keep the loan open while the Asset Desk arranges recovery. The laptop can still go through the normal cleanup. For a complete return, clear the borrower profile with the approved reset tool and wait for Reset successful. Only then set the status to Returned, record the receipt timestamp, and place the laptop on the ready shelf.

## End-of-day review

The service desk checks that all open loans in intake have a current status or a recorded owner. The return checklist separates ordinary issues from safety-related issues. If the desk receives an update on a hold, attach that update to the existing record. Use the existing incident log and asset register. Do not open a second loan record for the same return.
