# Publish a supplier price list

## Prerequisites

- Approved pricing CSV
- Supplier ID
- Catalog Admin access

## Procedure

1. Open **Imports** in Catalog Admin, select the supplier ID, and upload the approved CSV.
2. Review **Preview**. Compare the counts of new and updated items with the approved CSV. Resolve any count discrepancy before publishing.
   - If Preview flags duplicate SKUs, stop. The active catalog is unchanged. Request a corrected file from the supplier and restart at the upload step with the corrected, approved CSV.
   - If any price increases or decreases by more than 10%, obtain written approval from Merchandising before publishing.
3. Click **Publish** and confirm the batch status is **Applied**.
4. Open two affected SKUs and compare their prices with the approved CSV. If either price differs, contact Catalog Support without republishing.
5. Record the batch ID in the change log only after the batch shows **Applied** and both prices match the approved CSV.
