# Publish a supplier price list

## Prerequisites

- Approved pricing CSV
- Supplier ID
- Catalog Admin access

## Procedure

1. In Catalog Admin, open **Imports**, select the supplier ID, and upload the approved CSV.
2. Review the **Preview**. If it flags duplicate SKUs, stop. The active catalog is unchanged. Request a corrected file from the supplier and restart at the upload step with the corrected, approved CSV.
3. Compare the Preview’s new-item and updated-item counts with the approved CSV. If either count differs, stop before publishing.
4. If any price changes by more than 10%, obtain written approval from Merchandising before publishing.
5. Select **Publish** and confirm the batch status is **Applied**.
6. Open two affected SKUs and verify both prices against the approved CSV. If either price differs, contact Catalog Support and do not republish.
7. Record the batch ID in the change log after both prices match.
