# SOP: Publish a supplier price list

## Prerequisites

- Approved pricing CSV
- Supplier ID
- Catalog Admin access

## Upload and review

1. In Catalog Admin, open **Imports**, select the supplier ID, and upload the approved CSV.
2. Open **Preview**. Compare the **new** and **updated** item counts with the corresponding counts in the approved CSV. Confirm both counts match before proceeding.
3. If Preview flags duplicate SKUs, stop. The active catalog is unchanged. Request a corrected file from the supplier, then restart at the upload step.
4. If any price increases or decreases by more than 10%, obtain written approval from Merchandising before publishing.

## Publish and verify

1. Select **Publish** and confirm the batch status is **Applied**.
2. Open two affected SKUs and verify each price against the approved CSV.
3. If either price differs from the approved CSV, contact Catalog Support. Do not republish.
4. After both prices match, record the batch ID in the change log.
