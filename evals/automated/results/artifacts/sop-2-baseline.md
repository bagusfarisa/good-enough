# SOP: Publish a supplier price list

## Prerequisites

- Approved pricing CSV
- Supplier ID
- Catalog Admin access

## Upload and review

1. In Catalog Admin, open **Imports** and select the supplier ID.
2. Upload the approved pricing CSV and open **Preview**.
3. If Preview flags duplicate SKUs, stop before publishing. Request a corrected file from the supplier, then restart at the upload step with the corrected, approved CSV.
4. Compare the Preview counts for **new items** and **updated items** separately against the approved CSV. Continue only if both counts match.
5. If any price changes by more than 10%, obtain written approval from Merchandising before publishing.

## Publish and verify

1. Select **Publish** and confirm that the batch status is **Applied**.
2. Open two affected SKUs and compare each catalog price with its price in the approved CSV.
3. If either price differs, stop and contact Catalog Support. Do not republish.
4. Once both prices match, record the batch ID in the change log.
