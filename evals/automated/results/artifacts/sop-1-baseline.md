# SOP: Publish a supplier price list

## Prerequisites

- Approved pricing CSV
- Supplier ID
- Catalog Admin access

## Procedure

1. In Catalog Admin, open **Imports** and select the supplier ID.
2. Upload the approved pricing CSV and review the **Preview**. Compare the new item count and the updated item count with the counts in the approved CSV. Proceed only if both counts match.
3. If the preview flags duplicate SKUs, stop before publishing. Request a corrected file from the supplier, then restart at step 2 with the corrected file.
4. If any price changes by more than 10%, obtain written approval from Merchandising before publishing.
5. Select **Publish** and confirm that the batch status is **Applied**.
6. Open two affected SKUs and compare each published price with its price in the approved CSV. If either price differs, stop and contact Catalog Support. Do not republish.
7. Once both prices match, record the batch ID in the change log.
