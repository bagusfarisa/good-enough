# Publish a supplier price list

## Before you start

- Approved pricing CSV
- Supplier ID
- Catalog Admin access

## Procedure

1. In Catalog Admin, open **Imports**, select the supplier ID, and upload the approved CSV.
2. Review the **Preview**. Compare the new-item count and the updated-item count with the corresponding counts in the approved CSV. Resolve any count discrepancies before publishing.
   - If the Preview flags duplicate SKUs, stop. The active catalog is unchanged. Request a corrected file from the supplier and restart at the upload step with the corrected, approved CSV.
   - If any price changes by more than 10%, obtain written approval from Merchandising before publishing.
3. Click **Publish** and confirm that the batch status is **Applied**.
4. Open two affected SKUs and compare each displayed price with the approved CSV. If either price differs, contact Catalog Support and do not republish.
5. Once the batch shows **Applied** and both prices match, record the batch ID in the change log.
