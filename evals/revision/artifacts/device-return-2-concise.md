# Loaner laptop returns

## 1. Prepare for the return

- Find the loan in the asset register and check the recorded asset tag and due date.
- Ask the borrower to bring the laptop and charger. Have a reusable equipment bag ready for an ordinary return.

## 2. Check the laptop at intake

1. Scan the asset tag and compare it with the loan record. If it differs, set the status to **Check required**, refer the discrepancy to the Asset Desk, and keep the laptop in intake and the loan open until the Asset Desk resolves it. Stop processing the return.
2. If the tag matches, check for the charger and inspect the laptop before powering it on. Photograph surface scratches and continue. If you see battery swelling, follow the safety hold procedure below.

## 3. Handle visible battery swelling

1. Do not power on or charge the laptop. Move it to the designated battery isolation cabinet.
2. Set the status to **Safety hold** and call Facilities at extension **221**.
3. Record the asset tag, cabinet location, and time in the incident log. Keep the loan open until Facilities clears the hold.

## 4. Process an ordinary return

1. If the tag matches and there is no visible battery swelling, give the borrower a return acknowledgment.
2. If the charger is missing, set the status to **Accessories pending** and note the missing charger in the asset register. Continue normal cleanup and keep the loan open while the Asset Desk arranges recovery.
3. For a complete return, clear the borrower profile with the approved reset tool. Wait for **Reset successful**, then set the status to **Returned**, record the receipt timestamp, and place the laptop on the ready shelf.

## 5. Review open returns at close

- Check the daily return list. Verify that every open loan in intake has a current status or a recorded owner.
- Attach hold updates to the existing record. Use the existing asset register and incident log. Keep one loan record per return.
