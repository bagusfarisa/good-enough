# Loaner laptop return SOP

## 1. Prepare for the appointment

1. Find the loan in the asset register and check the recorded asset tag and due date.
2. Ask the borrower to bring the laptop and charger.
3. Prepare a reusable equipment bag for an ordinary return.

## 2. Verify the asset tag

1. Scan the laptop’s asset tag and compare it with the loan record.
2. If the tag differs, set the status to **Check required** and refer the discrepancy to the Asset Desk. Keep the laptop in intake and leave the loan open. Stop processing the return until the Asset Desk resolves the discrepancy.
3. If the tag matches, check whether the charger is present and inspect the laptop for damage before powering it on.

## 3. Handle damage

- **Visible battery swelling.** Do not power on or charge the laptop. Move it to the designated battery isolation cabinet, set the status to **Safety hold**, and call Facilities on extension **221**. Record the asset tag, cabinet location, and time in the incident log. Leave the loan open until Facilities clears the hold.
- **Surface scratches only.** Photograph the scratches and continue with the ordinary return.

## 4. Process an ordinary return

If the asset tag matches and there is no visible battery swelling, give the borrower a return acknowledgment.

- **Charger missing.** Set the status to **Accessories pending** and record the missing charger in the asset register. The laptop can go through normal cleanup. Keep the loan open while the Asset Desk arranges recovery.
- **Complete return.** Clear the borrower profile with the approved reset tool. Wait for **Reset successful** before setting the status to **Returned**. Then record the receipt timestamp and place the laptop on the ready shelf.

## 5. Review open returns at close

1. Check the daily return list. Verify that each open loan in intake has a current status or a recorded owner.
2. Attach any hold updates to the existing record. Use the existing incident log and asset register. Do not create a second loan record for the same return.
