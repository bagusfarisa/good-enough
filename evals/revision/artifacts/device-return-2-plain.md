# Loaner laptop return SOP

## 1. Prepare for the appointment

1. Find the loan record in the asset register. Check the recorded asset tag and due date.
2. Ask the borrower to bring the laptop and charger.
3. Prepare a reusable equipment bag for an ordinary return.

## 2. Verify the asset tag

1. Scan the laptop’s asset tag and compare it with the tag in the loan record.
2. If the tags differ, set the return status to **Check required** and refer the discrepancy to the Asset Desk. Keep the laptop in intake and the loan open until the Asset Desk resolves the discrepancy.
3. If the tags match, check whether the charger is present and inspect the laptop for visible damage before powering it on.

## 3. Handle visible damage

- **Visible battery swelling.** Do not power on or charge the laptop. Move it to the designated battery isolation cabinet, set the status to **Safety hold**, and call Facilities on extension **221**. Record the asset tag, cabinet location, and time in the incident log. Keep the loan open until Facilities clears it.
- **Surface scratches only.** Photograph the scratches and continue with the ordinary return.

## 4. Process an ordinary return

When the tag matches and there is no visible battery swelling, give the borrower an acknowledgment.

- **Charger missing.** Set the status to **Accessories pending** and record the missing charger in the asset register. The laptop can proceed through normal cleanup. Keep the loan open while the Asset Desk arranges recovery.
- **Laptop and charger received.** Clear the borrower profile with the approved reset tool. Wait for **Reset successful**. Then set the status to **Returned**, record the receipt timestamp in the asset register, and place the laptop on the ready shelf.

## 5. Review open returns at close

1. Check the daily return list. Verify that each open loan in intake has a current status or a recorded owner.
2. Attach any hold update to the existing record. Use the existing asset register and incident log, and keep a single loan record for each return.
