# Publish a supplier price list

## Prerequisites

- Approved pricing CSV
- Supplier ID
- Catalog Admin access

## Procedure

1. In Catalog Admin, open **Imports**, select the supplier ID, and upload the approved pricing CSV.
2. Review the **Preview** before publishing. Compare the new item count and the updated item count with the corresponding counts in the approved CSV. Proceed only when both counts match.
   - If the Preview flags duplicate SKUs, stop before publishing. The active catalog is unchanged. Request a corrected CSV from the supplier, then resume at the upload step and review the new Preview.
   - If any price changes by more than 10%, obtain written approval from Merchandising before publishing.
3. Select **Publish** and confirm that the batch status is **Applied**.
4. Open two affected SKUs and verify each price against the approved CSV. If either price differs, contact Catalog Support. Do not republish.
5. Record the batch ID in the change log only after both prices match the approved CSV.
