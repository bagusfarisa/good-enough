# SOP: Publish a supplier price list

## Prerequisites

- Approved pricing CSV
- Supplier ID
- Catalog Admin access

## Upload and review

1. In Catalog Admin, open **Imports** and select the supplier ID.
2. Upload the approved pricing CSV and open **Preview**.
3. If the preview flags duplicate SKUs, stop. The active catalog is unchanged. Request a corrected file from the supplier and restart at step 2 with the corrected, approved CSV.
4. Compare the preview’s counts of new and updated items with the corresponding counts in the approved CSV. Proceed only if both counts match.
5. If any price changes by more than 10%, obtain written approval from Merchandising before publishing.

## Publish and verify

1. Select **Publish** and confirm that the batch status is **Applied**.
2. Open two affected SKUs and compare their prices with the approved CSV.
3. If either price differs, contact Catalog Support without republishing.
4. Once both prices match, record the batch ID in the change log.
