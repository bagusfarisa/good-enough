# Publish a supplier price list

## Prerequisites

- Approved pricing CSV
- Supplier ID
- Catalog Admin access

## Procedure

1. In Catalog Admin, open **Imports** and select the supplier ID.
2. Upload the approved pricing CSV and open **Preview**.
3. Compare the new item count and the updated item count in **Preview** with the corresponding counts in the approved CSV. Both counts must match before you publish.
   - If **Preview** flags duplicate SKUs, stop. The active catalog is unchanged. Request a corrected CSV from the supplier and resume at step 2 once the corrected file is approved.
   - If any price changes by more than 10%, obtain written approval from Merchandising before publishing.
4. Select **Publish** and confirm that the batch status is **Applied**.
5. Open two affected SKUs and compare each price with the approved CSV. If either price differs, contact Catalog Support and leave the batch as is.
6. Once the batch shows **Applied** and both prices match, record the batch ID in the change log.
