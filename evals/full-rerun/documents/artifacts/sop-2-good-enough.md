# Publish a supplier price list

## Prerequisites

- Approved pricing CSV
- Supplier ID
- Catalog Admin access

## Procedure

1. In **Catalog Admin**, open **Imports**, select the supplier ID, and upload the approved pricing CSV.
2. Review the **Preview**. Compare the new item count and the updated item count with the corresponding counts in the approved CSV. Resolve any differences before publishing.
   - If the preview flags duplicate SKUs, stop. The active catalog remains unchanged. Request a corrected CSV from the supplier, then restart at the upload step with the approved, corrected file.
   - If any price changes by more than 10%, obtain written approval from Merchandising before publishing.
3. Select **Publish** and confirm that the batch status is **Applied**.
4. Open two affected SKUs and check both prices against the approved CSV. If either price differs, stop and contact Catalog Support without republishing.
5. Once the batch shows **Applied** and both prices match, record the batch ID in the change log.
