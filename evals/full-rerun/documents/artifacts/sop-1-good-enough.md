# Publish a supplier price list

Before you start, have the approved pricing CSV, the supplier ID, and access to Catalog Admin.

1. In **Catalog Admin**, open **Imports**, select the supplier ID, and upload the approved CSV.
2. Review the **Preview**. Compare the new-item and updated-item counts with the approved CSV. Continue only if both counts match.
   - If the preview flags duplicate SKUs, stop. The active catalog is unchanged. Request a corrected file from the supplier and restart at the upload step.
   - If any price changes by more than 10%, obtain written approval from Merchandising before publishing.
3. Select **Publish** and confirm the batch status shows **Applied**.
4. Open two affected SKUs and compare both prices with the approved CSV. If either price differs, contact Catalog Support without republishing.
5. After both prices match, record the batch ID in the change log.
