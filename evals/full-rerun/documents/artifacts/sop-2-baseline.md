# Publish a supplier price list

## Prerequisites

- Approved pricing CSV
- Supplier ID
- Catalog Admin access

## Upload and review

1. In **Catalog Admin**, open **Imports** and select the supplier ID.
2. Upload the approved pricing CSV and open **Preview**.
3. Compare the counts of new items and updated items in **Preview** with the counts in the approved CSV. Both counts must match before you publish.
4. If **Preview** flags duplicate SKUs, stop. The active catalog is unchanged. Request a corrected file from the supplier, then restart at the upload step.
5. If any price changes by more than 10%, obtain written approval from Merchandising before publishing.

## Publish and verify

1. Select **Publish** and confirm that the batch status is **Applied**.
2. Open two affected SKUs and compare each published price with its price in the approved CSV.
3. If either price differs, contact Catalog Support. Do not republish.
4. Once both prices match, record the batch ID in the change log.
