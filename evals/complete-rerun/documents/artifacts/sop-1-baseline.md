# Publish a supplier price list

## Prerequisites

- Approved pricing CSV
- Supplier ID
- Catalog Admin access

## Procedure

1. In Catalog Admin, open **Imports**, select the supplier ID, and upload the approved CSV.
2. Review **Preview** before publishing.
   - If Preview flags duplicate SKUs, stop. The active catalog is unchanged. Request a corrected file from the supplier. Once the corrected CSV is approved, return to the upload step.
   - Compare the new and updated item counts in Preview with the corresponding counts in the approved CSV. Proceed only when both counts match.
   - If any price changes by more than 10%, obtain written approval from Merchandising before publishing.
3. Select **Publish** and confirm that the batch status shows **Applied**.
4. Open two affected SKUs and verify that both prices match the approved CSV. If either price differs, contact Catalog Support without republishing.
5. Once both prices match, record the batch ID in the change log.
