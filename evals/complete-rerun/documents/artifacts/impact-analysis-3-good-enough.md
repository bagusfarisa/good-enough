# Return request expiry — launch impact analysis

After launch, in-scope return requests will expire after **seven calendar days in Awaiting customer documents**, counted from when the request enters that status. Customers will see **Expired** in the portal and can submit a new request. The expired request stays closed.

**For the launch discussion, Product needs to decide whether the rule applies to requests already open on launch day.** Until Product confirms the scope, Support and Operations should treat expiry dates for those requests as conditional. Communications still needs to decide whether to send an expiry email.

## What changes by status

| Request status | Today | After launch | Team action |
|---|---|---|---|
| Awaiting customer documents | The request stays open indefinitely unless someone closes it. | An in-scope request expires after seven calendar days in the status. The customer sees **Expired** in the portal. | Operations should count from the date the request entered the status. Support should explain how to submit a new request. |
| Internal review | The request stays open indefinitely unless someone closes it. | The request continues under the existing process. | Operations continues its current review process. |
| Completed or cancelled | The record is already closed. | The record remains as-is. | No action required. |
