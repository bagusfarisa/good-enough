# Publish a supplier price list

## Prerequisites

- Approved pricing CSV
- Supplier ID
- Catalog Admin access

## Import and review

1. In Catalog Admin, open **Imports** and select the supplier ID.
2. Upload the approved pricing CSV.
3. Open **Preview**. Compare the new-item and updated-item counts with the approved CSV. If either count differs, pause before publishing. The process owner needs to confirm how to resolve the discrepancy and where to resume.
4. Check the preview for duplicate SKUs and price changes greater than 10%.

   - **Duplicate SKUs.** Stop. The active catalog is unchanged. Request a corrected file from the supplier, then restart at step 2 with the corrected, approved CSV.
   - **Any price change greater than 10%.** Obtain written approval from Merchandising before publishing.
   - **Both conditions.** Follow the duplicate-SKU stop and restart at upload. The process owner needs to confirm whether written approval obtained for the original file carries over to the corrected file.

## Publish and verify

1. Select **Publish** after completing the preview checks and obtaining any required written approval.
2. Confirm that the batch status shows **Applied**.
3. Open two affected SKUs and verify each price against the approved CSV. If either price differs, stop and contact Catalog Support. Do not republish.
4. Record the batch ID in the change log only after the batch shows **Applied** and both prices match the approved CSV.
