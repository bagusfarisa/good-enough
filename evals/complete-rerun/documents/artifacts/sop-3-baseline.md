# Publish a supplier price list

## Prerequisites

- Approved pricing CSV
- Supplier ID
- Catalog Admin access

## Procedure

1. In Catalog Admin, open **Imports**, select the supplier ID, and upload the approved CSV.
2. Review the **Preview**. Compare the counts of new and updated items with the approved CSV.
   - If the preview flags duplicate SKUs, stop. The active catalog is unchanged. Request a corrected CSV from the supplier and restart at the upload step with the approved corrected file.
   - If either count differs from the approved CSV, stop and resolve the discrepancy before publishing.
3. If any price changes by more than 10%, obtain written approval from Merchandising before publishing.
4. Select **Publish** and confirm that the batch status shows **Applied**.
5. Open two affected SKUs and verify both prices against the approved CSV. If either price differs, stop and contact Catalog Support. Do not republish.
6. Record the batch ID in the change log after confirming the batch is **Applied** and both prices match.
