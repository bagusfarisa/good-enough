# Publish a supplier price list

## Before you start

Have the approved pricing CSV, the supplier ID, and Catalog Admin access.

## Publish and verify

1. In Catalog Admin, open **Imports**, select the supplier ID, and upload the CSV.
2. Review the **Preview** before publishing.
   - If the Preview flags duplicate SKUs, stop. The active catalog is unchanged. Request a corrected CSV from the supplier and restart at the upload step.
   - Compare the Preview’s new and updated item counts with the approved CSV. If either count differs, pause and ask the process owner how to proceed. The procedure does not define a restart step for count discrepancies.
   - If any price changes by more than 10%, obtain written approval from Merchandising before publishing. If the Preview also flags duplicate SKUs, stop and request the corrected CSV. Ask the process owner when to obtain Merchandising approval if both exceptions apply.
3. Select **Publish**. Confirm that the batch status shows **Applied**.
4. Open two affected SKUs and compare their prices with the approved CSV. If either price differs, contact Catalog Support without republishing.
5. After confirming **Applied** and verifying that both prices match, record the batch ID in the change log.
