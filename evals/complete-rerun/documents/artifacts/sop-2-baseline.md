# Publish a supplier price list

## Prerequisites

- Approved pricing CSV
- Supplier ID
- Catalog Admin access

## Procedure

1. In **Catalog Admin**, open **Imports**, select the supplier ID, and upload the approved CSV.
2. Open **Preview**. If it flags duplicate SKUs, stop. The active catalog remains unchanged. Request a corrected file from the supplier and restart at the upload step with the approved corrected CSV.
3. Compare the **Preview** counts for new and updated items with the corresponding counts in the approved CSV. Proceed only if both counts match.
4. If any price changes by more than 10%, obtain written approval from Merchandising before publishing.
5. Select **Publish** and confirm that the batch status is **Applied**.
6. Open two affected SKUs and verify both prices against the approved CSV. If either price differs, contact Catalog Support without republishing.
7. Record the batch ID in the change log only after confirming the **Applied** status and verifying that both prices match.
