# Publish a supplier price list

## Prerequisites

- Approved pricing CSV
- Supplier ID
- Catalog Admin access

## Procedure

1. In Catalog Admin, open **Imports**, select the supplier ID, and upload the approved CSV.
2. Review the **Preview**. Compare the new and updated item counts with the approved CSV.
   - If the preview flags duplicate SKUs, stop. The active catalog is unchanged. Request a corrected file from the supplier and restart at the upload in step 1.
   - If the counts differ, pause before publishing. Ask the process owner how to resolve the discrepancy.
   - If any price changes by more than 10%, obtain written approval from Merchandising before publishing.
3. Select **Publish** and confirm the batch status is **Applied**.
4. Open two affected SKUs and compare their prices with the approved CSV. If either price differs, contact Catalog Support. Do not republish.
5. Once the batch shows **Applied** and both prices match, record the batch ID in the change log.
