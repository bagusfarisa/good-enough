# Workshop handout print run

Start only after the Programs coordinator approves the agenda PDF. Keep the approved PDF and the layout draft in the print folder, and keep the draft private.

## 1. Build the proof

Import the approved agenda PDF into the draft using the approved print layout. Export one proof and mark it with the agenda version.

If the paper tray is empty, load the stock listed on the print ticket, then export one proof from the same approved agenda. If you also found an agenda mismatch, obtain the corrected, approved PDF before loading the stock and building the replacement proof.

## 2. Check the proof and release the run

Compare the printed session titles, room names, and times with the approved agenda. Ask Print Services to start the run only when all three match.

If any item differs, pause the run and ask the Programs coordinator for a corrected, approved agenda PDF. When it arrives, mark the previous proof **Superseded** and leave it in the print folder. Return to step 1 with the replacement PDF, then check the new proof before releasing the run.

## 3. Verify the run and sign the ticket

Count the copies against the print ticket and compare the first and last copies with the approved proof. Sign the ticket only when the count is correct and both copies match the proof.

If the count is off or either copy differs from the proof, report the mismatch to Print Services and leave the ticket unsigned.
