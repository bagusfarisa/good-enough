# Workshop handout print run

## Before you start

Get the agenda PDF approved by the Programs coordinator before preparing the handouts. Keep the approved PDF and the layout draft in the print folder. Use the approved print layout and keep the draft private.

## 1. Build and check one proof

1. Import the approved agenda PDF into the layout draft. Export one proof and mark it with the agenda version.
2. Compare the printed session titles, room names, and times with the approved agenda.
3. Ask Print Services to start the run only after all three match.

Handle these exceptions before releasing the run.

- **Agenda mismatch.** Pause the run and ask the Programs coordinator for a corrected, approved agenda PDF. Keep the previous proof in the print folder marked **Superseded**. When the replacement arrives, return to step 1 and build and check a fresh proof from it.
- **Empty paper tray.** Load the stock listed on the print ticket, then return to step 1 and export and check one proof from the same approved agenda.
- **Both occur.** Wait for the corrected, approved agenda PDF first. Then load the stock listed on the print ticket and return to step 1 with the replacement PDF. Keep the previous proof in the print folder marked **Superseded**.

## 2. Verify and sign off

1. Count the copies against the print ticket and compare the first and last copies with the approved proof.
2. Sign the ticket only if the count is correct and both copies match the proof. If the count is wrong or either copy differs, report the mismatch to Print Services and leave the ticket unsigned.
