# Workshop handout print run

Begin only after the Programs coordinator approves the agenda PDF. Keep the approved agenda PDF and the private layout draft in the print folder. Use the approved print layout.

## 1. Build proof

Import the approved agenda PDF into the layout draft. Export one proof copy and mark it with the agenda version.

If the paper tray is empty, load the stock listed on the print ticket. Resume by exporting one proof from the same approved agenda. If you also found an agenda mismatch, obtain the corrected, approved agenda PDF before loading the stock and building the replacement proof.

## 2. Check proof

Compare the printed session titles, room names, and times with the approved agenda PDF. Ask Print Services to start the run only when all three match.

If any title, room name, or time differs, pause the print run and ask the Programs coordinator for a corrected, approved agenda PDF. Mark the previous proof **Superseded** and keep it in the print folder. When the replacement PDF arrives, return to **1. Build proof** with the replacement and repeat the proof check.

## 3. Finish the run

Count the copies against the print ticket and compare the first and last copies with the approved proof. Sign the ticket only when the final count is correct and both copies match the proof. If the count or either copy differs, report the mismatch to Print Services and leave the ticket unsigned.
