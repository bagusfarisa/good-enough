# Workshop handout print run

Begin only after the Programs coordinator approves the agenda PDF. Keep the approved PDF and layout draft in the print folder, and keep the draft private.

## 1. Build the proof

Import the approved agenda PDF into the draft using the approved print layout. Export one proof copy, mark it with the agenda version, and print it for review.

## 2. Check the proof and release the run

Compare the printed session titles, room names, and times with the approved agenda. Ask Print Services to start the run only when all three match.

- **Agenda mismatch.** Pause the run and ask the Programs coordinator for a corrected, approved agenda PDF. When it arrives, mark the previous proof **Superseded** and keep it in the print folder. Return to step 1 with the replacement PDF, then check the fresh proof.
- **Empty paper tray.** Load the stock listed on the print ticket. Export and print one fresh proof from the same approved agenda, then check it.
- **Both issues.** Obtain the corrected, approved agenda PDF first. Then load the stock listed on the print ticket and follow the agenda mismatch steps to build and check the replacement proof.

## 3. Verify the run and sign the ticket

Count the copies against the print ticket and compare the first and last copies with the approved proof. Sign the ticket only when the count is correct and both copies match. If the count or printing differs, report the mismatch to Print Services and leave the ticket unsigned.
