# Publish a supplier price list

## Prerequisites

- Approved pricing CSV
- Supplier ID
- Catalog Admin access

## Procedure

1. In Catalog Admin, open **Imports**, select the supplier ID, and upload the approved CSV.
2. Review the **Preview** before publishing.
   - If the preview flags duplicate SKUs, stop. The active catalog is unchanged. Request a corrected CSV from the supplier, then restart at the upload step with the approved corrected file.
   - Compare the preview’s counts for new and updated items with the corresponding counts in the approved CSV. Proceed only if both counts match.
   - If any price changes by more than 10%, obtain written approval from Merchandising before publishing.
3. Select **Publish** and confirm the batch status shows **Applied**.
4. Open two affected SKUs and verify both prices against the approved CSV. If either price differs, stop and contact Catalog Support. Leave the batch as applied and await Support’s guidance before taking any further publishing action.
5. Record the batch ID in the change log only after confirming the batch shows **Applied** and both prices match.
