# Publish a supplier price list

**Before you start:** Have the approved pricing CSV, the supplier ID, and access to Catalog Admin.

1. In Catalog Admin, open **Imports**, select the supplier ID, and upload the approved CSV.
2. Open **Preview**. If it flags duplicate SKUs, stop. The active catalog is unchanged. Request a corrected file from the supplier and restart at the upload step with the corrected, approved CSV.
3. Compare the preview’s new and updated item counts with the corresponding counts in the approved CSV. Proceed only if both counts match. If any price changes by more than 10%, obtain written approval from Merchandising before proceeding.
4. Select **Publish** and confirm the batch status shows **Applied**.
5. Open two affected SKUs and verify their prices against the approved CSV. If either price differs, contact Catalog Support and do not republish.
6. After both prices match, record the batch ID in the change log.
