# Publish a supplier price list

Before you start, have the approved pricing CSV, the supplier ID, and access to Catalog Admin.

1. In Catalog Admin, open **Imports**, select the supplier ID, and upload the approved CSV.
2. Open **Preview**. If it flags duplicate SKUs, stop. The active catalog is unchanged. Request a corrected file from the supplier, then restart at the upload step with the corrected, approved CSV.
3. Compare the preview’s new and updated item counts with the approved CSV. If either count differs, pause before publishing until the discrepancy is resolved.
4. If any price changes by more than 10%, obtain written approval from Merchandising before proceeding.
5. Select **Publish** and confirm that the batch status shows **Applied**.
6. Open two affected SKUs and compare their prices with the approved CSV. If either price differs, stop and contact Catalog Support. Leave the batch as it is while Support investigates.
7. Once both prices match, record the batch ID in the change log.
