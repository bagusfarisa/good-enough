# Publish a supplier price list

## Prerequisites

- Approved pricing CSV
- Supplier ID
- Access to Catalog Admin

## Procedure

1. In Catalog Admin, open **Imports**, select the supplier ID, and upload the approved CSV.
2. Review the **Preview**. Compare both the new-item count and the updated-item count with the approved CSV. Continue only if both counts match.
   - If the Preview flags duplicate SKUs, stop. The active catalog is unchanged. Request a corrected file from the supplier, then return to the upload step with the corrected, approved CSV.
   - If any price changes by more than 10%, obtain written approval from Merchandising before publishing.
3. Select **Publish** and confirm that the batch status shows **Applied**.
4. Open two affected SKUs and verify each price against the approved CSV. If either price differs, contact Catalog Support and do not republish.
5. Record the batch ID in the change log only after both prices match.
