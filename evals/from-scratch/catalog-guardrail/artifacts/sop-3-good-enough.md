# Publish a supplier price list

## Prerequisites

- Approved pricing CSV
- Supplier ID
- Catalog Admin access

## Procedure

1. In Catalog Admin, open **Imports**, select the supplier ID, and upload the approved pricing CSV.
2. Review the **Preview**. Compare the counts of new and updated items with the corresponding counts in the approved CSV.
   - If the counts differ, stop before publishing.
   - If the preview flags duplicate SKUs, stop. The active catalog is unchanged. Request a corrected file from the supplier, then resume at the upload step with the approved corrected CSV.
   - If any price changes by more than 10%, obtain written approval from Merchandising before publishing.
3. Select **Publish** and confirm that the batch status is **Applied**.
4. Open two affected SKUs and verify each price against the approved CSV. If either price differs, contact Catalog Support and do not republish.
5. Record the batch ID in the change log only after the batch shows **Applied** and both prices match.
