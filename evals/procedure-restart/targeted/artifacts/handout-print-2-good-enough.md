# Workshop handout print run

## Before you start

Wait for the Programs coordinator to approve the agenda PDF. Keep the approved PDF and the layout draft in the print folder. Use the approved print layout and keep the draft private.

## 1. Build the proof

Import the approved agenda PDF into the layout draft. Export one proof copy and mark it with the agenda version.

If the paper tray is empty, load the stock listed on the print ticket and resume by exporting one proof from the same approved agenda. If you also find an agenda mismatch, follow the correction steps below before loading paper.

## 2. Check the proof and release the run

Compare the printed session titles, room names, and times with the approved agenda. Ask Print Services to start the run only when all three match.

If any title, room name, or time differs:

1. Pause the run and ask the Programs coordinator for a corrected, approved agenda PDF.
2. When the replacement arrives, mark the previous proof **Superseded** and leave it in the print folder. If the tray is empty, load the stock listed on the print ticket now.
3. Return to **Build the proof** with the replacement PDF, then repeat **Check the proof and release the run**.

## 3. Verify and sign off

Count the copies against the print ticket and compare the first and last copies with the approved proof. Sign the ticket only when both copies match the proof and the count matches the ticket. If any check fails, report the mismatch to Print Services and leave the ticket unsigned.
