# Workshop handout print run

Begin only after the Programs coordinator approves the agenda PDF. Keep the approved PDF and the layout draft in the print folder. Use the approved print layout and keep the draft private.

## 1. Build the proof

Import the approved agenda PDF into the layout draft. Export one proof copy and mark it with the agenda version.

If the paper tray is empty, load the stock listed on the print ticket. Resume by exporting one proof from the same approved agenda. If you also found an agenda mismatch, follow the combined exception in step 2.

## 2. Check the proof and start the run

Compare the printed session titles, room names, and times with the approved agenda. Ask Print Services to start the run only when all three match.

- **Agenda mismatch.** Pause the run and ask the Programs coordinator for a corrected, approved agenda PDF. Keep the previous proof in the print folder marked **Superseded**. When the corrected PDF arrives, return to step 1 with the replacement PDF, then repeat step 2.
- **Agenda mismatch and empty tray.** Follow the agenda mismatch procedure and wait for the corrected, approved PDF. Then load the stock listed on the print ticket, return to step 1 with the replacement PDF, and repeat step 2.

## 3. Verify the run and sign the ticket

Count the copies and compare the total with the print ticket. Check the first and last copies against the approved proof.

Sign the ticket only when the count is correct and both copies match the proof. If you find a count or print mismatch, report it to Print Services and leave the ticket unsigned.
