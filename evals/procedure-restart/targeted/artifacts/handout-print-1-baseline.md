# Workshop handout print run

Start only after the Programs coordinator approves the agenda PDF. Keep the approved PDF and the layout draft in the print folder. Use the approved print layout and keep the draft private.

## 1. Build and check the proof

1. Import the approved agenda PDF into the layout draft. Export one proof copy and mark it with the agenda version.
2. Compare the session titles, room names, and times on the printed proof with the approved agenda PDF. Ask Print Services to start the run only when all three match.

If a session title, room name, or time differs, pause the run and ask the Programs coordinator for a corrected, approved agenda PDF. Keep the previous proof in the print folder and mark it **Superseded**. When the replacement PDF arrives, repeat steps 1 and 2 using that PDF.

If the paper tray is empty, load the stock listed on the print ticket, export one proof from the same approved agenda PDF, and repeat the proof check. If you also found an agenda mismatch, get the corrected, approved PDF first. Then load the stock, build the replacement proof, and check it before asking Print Services to start the run.

## 2. Verify and sign off

1. Count the copies and compare the total with the print ticket. Compare the first and last copies with the approved proof.
2. Sign the print ticket only when the count is correct and both copies match the approved proof. If the count or either copy differs, report the mismatch to Print Services and leave the ticket unsigned.
