# Workshop handout print run

Before you start, confirm that the Programs coordinator has approved the agenda PDF. Keep the approved PDF and the private layout draft in the print folder.

1. **Build one proof.** Import the approved agenda PDF into the draft using the approved print layout. Export one proof, mark it with the agenda version, and print it. If the paper tray is empty, load the stock listed on the print ticket and export one proof from the same approved agenda before printing it.
2. **Check the printed proof.** Compare the session titles, room names, and times with the approved agenda. Ask Print Services to start the run only when all three match. If any differ, pause the run and ask the Programs coordinator for a corrected, approved agenda PDF. Mark the previous proof **Superseded** and keep it in the print folder. When the corrected PDF arrives, return to step 1 with the replacement PDF and check the new proof. If the tray is also empty, wait for the corrected PDF, then load the stock before building the replacement proof.
3. **Verify the run and sign the ticket.** Count the copies against the print ticket and compare the first and last copies with the approved proof. Sign only when the count is correct and both copies match. Report any count or print mismatch to Print Services and leave the ticket unsigned.
