# Workshop handout print run

Prepare the workshop handouts only after the Programs coordinator approves the agenda PDF. Keep the approved agenda and the layout draft in the print folder.

## Build proof

Import the approved agenda PDF into the layout draft and export one proof copy. Mark the proof with the agenda version. Use the approved print layout and keep the draft private.

## Check proof

Compare the printed session titles, room names, and times with the approved agenda. Ask Print Services to start the run only after all three match. If an agenda title, room name, or time differs, pause the print run and ask the Programs coordinator for a corrected, approved agenda PDF. When it arrives, return to Build proof. Import the replacement, export a fresh proof, and repeat Check proof. Leave the previous proof in the print folder marked Superseded.

If the paper tray is empty, load the stock listed on the print ticket. Resume by exporting one proof from the same approved agenda. If both an agenda mismatch and an empty tray occur, complete the agenda correction first. Then load the stock and build the replacement proof.

## Finish the run

Count the copies against the print ticket. Sign the ticket only when the first and last copies match the approved proof and the final count is correct. Report any count or print mismatch to Print Services and leave the ticket unsigned.
