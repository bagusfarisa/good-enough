# SOP: Publish a Supplier Price List

## Prerequisites

- Approved pricing CSV
- Supplier ID
- Catalog Admin access

## 1. Upload the price list

In Catalog Admin, open **Imports**, select the supplier ID, and upload the approved CSV.

## 2. Review the preview

1. Open **Preview**. If it flags duplicate SKUs, stop. The active catalog is unchanged. Request a corrected file from the supplier, then restart at the upload step.
2. Compare the preview’s new-item and updated-item counts with the corresponding counts in the approved CSV. Continue only if both counts match.
3. If any price changes by more than 10%, obtain written approval from Merchandising before publishing.

## 3. Publish and verify

1. Press **Publish** and confirm the batch shows **Applied**.
2. Open two affected SKUs and verify each price against the approved CSV.
3. If either price differs from the approved CSV, contact Catalog Support and do not republish.
4. Record the batch ID in the change log only after both prices match.
