# Publish a supplier price list

## Prerequisites

- Approved pricing CSV
- Supplier ID
- Catalog Admin access

## Procedure

1. In Catalog Admin, open **Imports**, select the supplier ID, and upload the approved CSV.
2. Review the **Preview** before publishing. Compare the new and updated item counts against the approved CSV. Proceed only if both counts match.
   - If the preview flags duplicate SKUs, stop. The active catalog is unchanged. Request a corrected file from the supplier, then restart at the upload step with the corrected, approved CSV.
   - If any price changes by more than 10%, obtain written approval from Merchandising before publishing.
3. Select **Publish** and confirm that the batch status shows **Applied**.
4. Open two affected SKUs and verify that both prices match the approved CSV. If either price differs, stop and contact Catalog Support. Do not republish.
5. Record the batch ID in the change log only after the batch shows **Applied** and both price checks pass.
