# Publish a supplier price list

## Prerequisites

- Approved pricing CSV
- Supplier ID
- Catalog Admin access

## Procedure

1. In **Catalog Admin**, open **Imports**, select the supplier ID, and upload the approved CSV.
2. Open **Preview**. Compare the new and updated item counts with the approved CSV. Confirm both counts match before proceeding.
   - If Preview flags duplicate SKUs, stop. The active catalog is unchanged. Request a corrected file from the supplier and restart at the upload step with the corrected, approved CSV.
   - If any price changes by more than 10%, obtain written approval from Merchandising before publishing.
3. Select **Publish** and confirm the batch status is **Applied**.
4. Open two affected SKUs and verify each price against the approved CSV. If either price differs, stop and contact Catalog Support. Do not republish.
5. Once the batch shows **Applied** and both prices match, record the batch ID in the change log.
