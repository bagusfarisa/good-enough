# Publish a supplier price list

## Prerequisites

- Approved pricing CSV
- Supplier ID
- Catalog Admin access

## Procedure

1. In Catalog Admin, open **Imports** and select the supplier ID.
2. Upload the approved CSV and open **Preview**.
3. Review the preview before publishing.
   - If the preview flags duplicate SKUs, stop. The active catalog is unchanged. Request a corrected file from the supplier, then restart at step 2.
   - Compare the new-item count and the updated-item count with the approved CSV. Proceed only if both counts match.
   - If any price changes by more than 10%, obtain written approval from Merchandising before publishing.
4. Select **Publish** and confirm that the batch status is **Applied**.
5. Open two affected SKUs and verify both prices against the approved CSV. If either price differs, contact Catalog Support without republishing.
6. Record the batch ID in the change log only after the batch shows **Applied** and both prices match the approved CSV.
