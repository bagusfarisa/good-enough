# SOP — Publish a supplier price list

## Prerequisites

- Approved pricing CSV
- Supplier ID
- Catalog Admin access

## Procedure

1. In Catalog Admin, open **Imports**, select the supplier ID, and upload the approved pricing CSV.
2. Review the **Preview**. Compare the counts of new and updated items with the corresponding counts in the approved CSV.
3. If the preview flags duplicate SKUs, stop. The active catalog is unchanged. Request a corrected file from the supplier, then restart at the upload step.
4. If any price changes by more than 10%, obtain written approval from Merchandising before proceeding.
5. Select **Publish**. Confirm that the batch status is **Applied**.
6. Open two affected SKUs and compare each catalog price with its price in the approved CSV. If either price differs, contact Catalog Support without republishing.
7. After both prices are verified, record the batch ID in the change log.
